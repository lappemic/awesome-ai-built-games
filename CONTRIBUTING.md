# Contributing

Built a game with AI, or found one worth playing? Submissions are welcome.

## Two ways to submit

1. **No Markdown needed:** [open a game submission](https://github.com/lappemic/awesome-ai-built-games/issues/new?template=submit-game.yml) and fill in the form.
2. **Pull request:** add the entry to `README.md` yourself (format below).

Every submission is reviewed by hand. This is a curated list, not a collection, so not every game will be added.

## What gets in

- **Built mostly with AI.** Most of the code was written by AI coding tools (Claude Code, Cursor, Codex, Copilot, Lovable, Bolt, v0, Gemini, Grok, ChatGPT, …). Please link something that shows it, such as a post, devlog, README or jam page.
- **Playable right now.** A working link that runs in the browser, or a download page. No waitlists, dead links or "coming soon".
- **Worth someone's time.** It is polished, original, technically ambitious or has an interesting story. Plain clones of Snake, Pong or Tetris need a real twist.
- **No low-effort portals.** Sites hosting hundreds of auto-generated games belong in [Directories](README.md#directories), if anywhere.

## Entry format

```md
- [Game Name](https://link-to-the-game) - What you actually do in the game, in one sentence. Built with Claude Code · Three.js.
```

- Add it to the matching category, in alphabetical order.
- The description starts with a capital letter, does not repeat the game's name, and ends with a period.
- Skip hype words ("amazing", "ultimate", "most addictive").
- Name the AI tools and the engine after "Built with", separated by `·`, but only what you can back up.

Dead link, wrong info or your own game listed and you want it removed? [Open an issue](https://github.com/lappemic/awesome-ai-built-games/issues/new) or send a pull request.
