# Contributing

Built a game with AI, or found one worth playing? Submit it in one of two ways:

1. **Form, no Markdown needed:** [open a game submission](https://github.com/lappemic/awesome-ai-built-games/issues/new?template=submit-game.yml).
2. **Pull request:** add the entry to `README.md` in the [entry format](#entry-format).

Every submission is reviewed by hand. This is a curated list, so not every game gets in.

## What gets in

- **Built mostly with AI.** AI coding tools (Claude Code, Cursor, Codex, Copilot, Lovable, Bolt, v0, Gemini, Grok, ChatGPT, …) wrote most of the code. Link something that shows it, such as a post, devlog, README or jam page.
- **Playable right now.** A working browser link or download page. No waitlists, dead links or "coming soon".
- **Worth someone's time.** Polished, original, technically ambitious or with an interesting story. Plain clones of Snake, Pong or Tetris need a real twist.
- **No low-effort portals.** Sites hosting hundreds of auto-generated games belong in [Directories](README.md#directories), if anywhere.

## Entry format

```md
- [Game Name](https://link-to-the-game) - What you do in the game, in one sentence. Built with Claude Code · Three.js.
```

- Add it to the matching category, in alphabetical order.
- Start the description with a capital letter, don't repeat the game's name, and end with a period.
- Skip hype words ("amazing", "ultimate", "most addictive").
- After "Built with", list only the AI tools and engine you can back up, separated by `·`.

## Got listed?

Add the badge to your project:

```md
[![Mentioned in Awesome AI-Built Games](https://awesome.re/mentioned-badge.svg)](https://github.com/lappemic/awesome-ai-built-games)
```

## Removals and fixes

Dead link, wrong info, or want your own game removed? [Open an issue](https://github.com/lappemic/awesome-ai-built-games/issues/new) or send a pull request.
